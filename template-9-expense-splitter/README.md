# 💰 Roommate Expense Splitter

**Stop arguing about who owes what!**

Living with roommates is great until it's time to split bills. This app tracks shared expenses, calculates who owes whom, and suggests the minimum number of transactions to settle up. The AI version can even scan receipt photos!

## 🎯 What This App Does

- **Track expenses**: Add groceries, utilities, household items
- **Flexible splitting**: Equal split, by person, or custom amounts
- **Balance tracking**: See who owes what at a glance
- **Smart settlements**: Minimize the number of payments needed
- **Receipt scanning**: Upload receipt photos → auto-extract items (AI version)
- **Export reports**: Monthly summaries for record-keeping

## 🚀 Quick Start

```bash
cd template-9-expense-splitter
pip install -r requirements.txt
echo "ANTHROPIC_API_KEY=your_key_here" > .env  # For receipt scanning
streamlit run app.py
```
