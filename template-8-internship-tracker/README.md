# 💼 Internship Application Tracker

**Never lose track of your internship applications again!**

Apply to dozens of positions without losing your mind. Track applications, deadlines, interview stages, and follow-ups all in one place. The AI version provides application strategy insights and generates follow-up emails.

## 🎯 What This App Does

- **Track applications**: Company, role, status, deadlines
- **Manage pipeline**: Applied → Interview → Offer → Accepted/Rejected
- **Set reminders**: Never miss a follow-up or deadline
- **Store materials**: Save cover letters and resumes per company
- **Analytics**: Visualize success rates and application patterns
- **AI insights**: Get strategy suggestions and email templates (advanced)

## 🚀 Quick Start

```bash
cd template-8-internship-tracker
pip install -r requirements.txt
echo "ANTHROPIC_API_KEY=your_key_here" > .env  # For AI features
streamlit run app.py
```
