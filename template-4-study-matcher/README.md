# 🤝 Study Group Matcher

**Find the perfect study partners for your courses!**

Match with classmates based on courses, learning styles, availability, and location preferences. The AI version uses Claude to create intelligent matches and facilitate introductions.

## 🎯 What This App Does

- **Create profiles**: Add your courses, learning style, and availability
- **Find matches**: Discover potential study partners
- **AI matching**: Smart recommendations based on compatibility (advanced)
- **Coordinate meetups**: Share availability and preferred study spots
- **Track study sessions**: Log and rate study group effectiveness

## 🚀 Quick Start

```bash
cd template-4-study-matcher
pip install -r requirements.txt
echo "ANTHROPIC_API_KEY=your_key_here" > .env  # For advanced version
streamlit run app.py  # or app_advanced.py
```
