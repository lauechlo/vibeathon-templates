# 📖 Precept Prep Assistant

**Ace your precepts with AI-generated discussion questions!**

Upload readings, get instant summaries, discussion questions, and key concepts. Perfect for humanities courses and precept preparation.

## 🎯 What This App Does

- **Paste readings**: Copy/paste text from your readings
- **Get summaries**: Quick TL;DR of key points
- **Discussion questions**: AI-generated questions for precept
- **Key concepts**: Important terms and ideas extracted
- **Argument analysis**: Practice both sides of debates (advanced)

## 🚀 Quick Start

```bash
cd template-5-precept-prep
pip install -r requirements.txt
echo "ANTHROPIC_API_KEY=your_key_here" > .env
streamlit run app.py  # Beginner version
streamlit run app_advanced.py  # Full AI version
```
